# Bidirectional LSTM for News Text Classification

## Project Overview

This project implements a deep learning-based text classification model using a Bidirectional Long Short-Term Memory (BiLSTM) neural network.

The model is trained on a news dataset containing news titles, article text, subjects, dates, and class labels. The objective is to classify news articles based on their textual content.

## Dataset

The dataset contains news articles with features such as:

- title`
- text`
- subject`
- date`
- class`

The target variable is  class`.

## Project Workflow

1. Load the news dataset
2. Explore the dataset
3. Clean and preprocess the text
4. Tokenize the text
5. Convert text into numerical sequences
6. Apply padding
7. Create the Bidirectional LSTM model
8. Train the model
9. Evaluate model performance
10. Analyze the classification results

## Model

The project uses a Bidirectional LSTM architecture to process text sequences from both forward and backward directions.

This allows the model to capture contextual information from both sides of a sequence.

# How to Run

1. Clone the repository.
2. Open  Bidirectional_LSTMRNN.ipynb` using Jupyter Notebook or Google Colab.
3. Make sure News.csv  is available in the project directory.
4. Run the notebook cells sequentially.
